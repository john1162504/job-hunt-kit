# Examples

This folder is for optional sample artefacts you may want to keep in a private fork
(e.g. a redacted notes.md style). The kit itself does not require anything here.

Suggested practice when sharing the kit publicly:

- Keep `applications/` and `daily-runs/` empty
- Keep `tracked-jobs.json` as `{"jobs": []}`
- Ship only `config.example.json` (not your real `config.json`)
